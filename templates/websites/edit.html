PHP Agent Sensor (Konektor Host-Based Monitoring)
Metode Sensor Lokal – Tanpa Mengubah DNS / IP Domain
Mendukung PHP & Laravel
Kapan Menggunakan Metode Ini?
Gunakan metode ini jika website Anda di-hosting di Shared Hosting (cPanel) dan Anda tidak ingin mengubah pengaturan DNS A-Record. Penyerang menembak langsung ke domain asli Anda, dan sensor PHP di server akan secara otomatis mengirimkan telemetri serangan ke NIDS.
1 Unduh File Sensor Otomatis
File nids_agent.php ini sudah langsung terkonfigurasi dengan API Key dan Server URL website ini.
Unduh nids_agent.php
Simpan file ini ke dalam folder public/ website Laravel Anda.
2 Sisipkan 1 Baris Kode Aman (Prinsip Fail-Open)
Buka file public/index.php di website target Anda, lalu sisipkan blok kode di bawah ini pada baris paling atas setelah tag <?php: 
// Sensor NIDS Monitor (Fail-Open: Website dijamin tidak akan pernah error)
try {
    if (file_exists(__DIR__ . '/nids_agent.php')) {
        require_once __DIR__ . '/nids_agent.php';
    }
} catch (\Throwable $e) {}
Dilengkapi blok try-catch (\Throwable) sehingga jika server NIDS mati, website Anda tetap berjalan normal 100%.
