📦 Instruksi Pemasangan
1
Download File Konektor Agen NIDS
File ini sudah otomatis terkonfigurasi dengan API Key website ini:
⬇️ Download nids_agent.php (Otomatis Terisi API Key)
2
Letakkan di Folder public/ Proyek Laravel
Pindahkan berkas nids_agent.php ke dalam folder public/ website Laravel Anda.
Contoh path: D:\laragon\www\htdocs\rekam-medis-chacha20\public\nids_agent.php
3
Sisipkan 1 Baris Kode di public/index.php
Buka file public/index.php website Anda, tambahkan baris berikut tepat di bawah tag <?php:
if (file_exists(__DIR__ . '/nids_agent.php')) {
    require_once __DIR__ . '/nids_agent.php';
}
4
Jalankan Laravel dengan Bind ke Semua IP (Penting untuk Testing LAN)
Jika ingin menguji serangan dari mesin lain (Kali Linux di LAN), jalankan Laravel dengan bind ke semua interface agar bisa diakses dari luar localhost: 
php artisan serve --host=0.0.0.0 --port=8000
Setelah itu akses website dari Kali Linux melalui IP host (misal: http://192.168.1.12:8000). IP penyerang akan tercatat secara otomatis di dashboard NIDS.
5
Verifikasi – Cek Dashboard NIDS
Buka browser dan akses halaman website Laravel Anda. Setiap request (normal maupun serangan SQLi/XSS/DDoS) akan otomatis terkirim dan dianalisis oleh NIDS Monitor. Cek dashboard untuk melihat hasilnya!
