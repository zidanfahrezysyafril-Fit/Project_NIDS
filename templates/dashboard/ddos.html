Penyebab Pengujian Sekuensial Gagal: Web server backend lokal (PHP) memproses 1 request dalam ~0.5–1.0 detik. Jika Anda menjalankan curl berurutan satu demi satu, hanya ~10–15 request yang selesai dalam jendela 10 detik, sehingga ambang batas tidak pernah terlampaui. Gunakan perintah konkurensi di bawah agar request dikirim serentak:
Metode A: Concurrent cURL Loop (Bash) 
for i in {1..35}; do curl -s -o /dev/null -w "%{http_code}\n" http://10.0.2.2:5000/gateway/{{ site.id }}/ & done; wait
Mengirim 35 request serentak di latar belakang. Respons akan langsung berubah menjadi 429 (Too Many Requests).
Metode B: Apache Benchmark (ab) 
ab -n 40 -c 10 http://10.0.2.2:5000/gateway/{{ site.id }}/
Mengirim total 40 request dengan konkurensi 10. Non-2xx responses menandakan blokir NIDS aktif.
